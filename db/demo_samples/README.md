# ゲスト表示用PDF

利用者が指定した教材と手書き答案（各1ページ）です。氏名・学校・学級・番号欄は空欄で、全ページと文書メタデータを確認しています。PDFは提供時のバイト列を保持し、`Demo::Sample` のSHA-256で照合します。

問題・解答・70点の結果表示は、人が内容を確認して作成した固定サンプルです。実AIは呼び出していません。`demo-sample-no-ai` と画面の説明を維持します。答案の3問の誤答もそのまま表示します。2(3)の最終記載「4/6」は変更せず、既存の採点方針に合わせて未約分として誤答にしています。

新しい隔離デモの明示的な初期化時だけ利用します。既存の公開デモを自動で再seed・修復・再baselineする変更ではありません。公開反映には既存デモの保持と別途レビュー済みの切替が必要です。本番の通常学校データには利用しません。
