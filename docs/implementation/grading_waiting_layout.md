# #162 採点中表示の配置

| 状態 | 左カラム（答案PDF） | 右カラム（採点結果） |
| --- | --- | --- |
| 提出済み・採点中 | PDFの上に中央揃えの円3個と現在の状態文。PDF閲覧は継続 | 状態と点数欄 |
| 完了 | 待機領域を消してPDFを表示 | 採点結果を直ちに表示 |

検証画像は隔離環境の `issue162-evidence/before/` と `after/` に保存。架空答案だけを使用。実機・本番での表示は未確認。
